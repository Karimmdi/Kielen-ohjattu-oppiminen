# Kielen ohjattu oppiminen

## Esivaatimukset

1. Python tulkki
2. Google Gemini API avain

## Ohjelman ajaminen (Windows)

1. Navigoi projektin juureen
2. Luo tiedosto .env ja lisää sinne rivi:
```
GEMINI_API_KEY="sinun_api_avaimesi"
```
3. Aja seuraava komento terminaalissa:
```bash
python .\main.py
```
